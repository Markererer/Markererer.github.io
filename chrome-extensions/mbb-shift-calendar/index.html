MBB Shift Calendar

Keep assigned and available MBB shifts visible in Google Calendar, with separate calendars for each type of shift.

  • Install from Chrome Web Store

Overview

MBB Shift Calendar is a Chrome extension for MBB Buddy Ride users. It reads assigned and available shifts from the MBB schedule and creates corresponding events in two separate Google Calendars:

  • MBB - Assigned Shifts
  • MBB - Available Shifts

The extension avoids creating duplicate events, shows sync progress, and reports errors when a sync cannot be completed.

How it works

  1. Enter your MBB login credentials in the extension.
  2. Authorize Google Calendar access through Google OAuth.
  3. Start a sync to read the MBB schedule and create or update the matching shift events.

Calendar data is checked for existing matching events before new events are created. The extension shows progress during the sync and displays an error message if MBB or Google Calendar cannot be reached.

Google Calendar access

Google Calendar access is requested through Google OAuth. The extension uses Calendar data only to create shift events and check for duplicates in the two MBB shift calendars. It does not use that access for advertising, analytics, tracking, or any unrelated purpose.

Privacy and data handling

MBB login credentials are entered by the user. The email address may be stored locally if the user chooses the remember-login option. The password is stored locally only when the user explicitly enables that option; otherwise, the password is discarded after the sync.

MBB shift information is processed to create calendar events. The extension has no separate backend server. Data is communicated only with the MBB website and the Google Calendar API as needed for the stated functionality. The extension does not sell data, use data for advertising, or use analytics or tracking.
